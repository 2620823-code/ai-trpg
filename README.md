# AI-TRPG

새로 개발하는 판타지 TRPG 프로젝트입니다. 기존 `dice-rpg` 저장소 및 DICE RPG Ver 1.4 파일은 별도로 보존하며 이 저장소에서 수정하지 않습니다.

## 현재 프로토타입
- 풀스크린 중심의 반응형 게임 화면
- 바텀웨이마을 초기 장면과 모험가 캐릭터 콘셉트
- CSS 기반 대기, 이동, 대화, 검 휘두르기 애니메이션
- 이동·대화·장소 조사·훈련 로그
- 브라우저 로컬 저장을 이용한 초기 활동 기록
- PC 및 모바일 레이아웃 대응

## 실행
정적 웹 프로젝트입니다. `index.html`을 정적 서버로 열거나 Vercel에 배포할 수 있습니다.

## 구현 경계
이 버전은 시각·조작 프로토타입입니다. 실제 계정 인증, 클라우드 저장, 멀티플레이, AI Game Master API, 주사위 기반 명중/방어 판정, 완성된 캐릭터 생성/성장, 확정된 전체 지도와 세계 데이터는 아직 연결되지 않았습니다. 임시 UI 값은 실제 게임 규칙으로 간주하지 않습니다.

공격 연습 버튼은 시각 효과만 재생하며 피해나 명중 판정을 실행하지 않습니다. 실제 전투 구현에서는 기존 DICE RPG의 명중률·명중·방어 규칙을 원본 기준으로 이식하되, 두 프로젝트의 코드는 독립적으로 유지합니다.
