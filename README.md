# AI-TRPG

새로 개발하는 판타지 TRPG 프로젝트입니다. 기존 `dice-rpg` 저장소 및 DICE RPG Ver 1.4 파일은 별도로 보존하며 이 저장소에서 수정하지 않습니다.

## 현재 프로토타입
- 풀스크린 중심의 반응형 게임 화면
- 바텀웨이마을 초기 장면과 모험가 캐릭터 콘셉트
- CSS 기반 대기, 이동, 대화, 검 휘두르기 애니메이션
- 이동·대화·장소 조사·훈련 로그
- 브라우저 로컬 저장을 이용한 초기 활동 기록
- PC 및 모바일 레이아웃 대응

## 실행
정적 웹 프로젝트입니다. `index.html`을 정적 서버로 열거나 Vercel에 배포할 수 있습니다.

## 구현 경계
이 버전은 시각·조작 프로토타입입니다. 실제 계정 인증, 클라우드 저장, 멀티플레이, AI Game Master API, 주사위 기반 명중/방어 전투 엔진, 레벨 성장, 확정된 전체 지도와 세계 데이터는 아직 연결되지 않았습니다. 종족·직업 선택과 기본 능력치 생성은 로컬 프로토타입에 연결했습니다. 임시 UI 값은 실제 게임 규칙으로 간주하지 않습니다.

공격 연습 버튼은 시각 효과만 재생하며 피해나 명중 판정을 실행하지 않습니다. 실제 전투 구현에서는 기존 DICE RPG의 명중률·명중·방어 규칙을 원본 기준으로 이식하되, 두 프로젝트의 코드는 독립적으로 유지합니다.

## 2026-11-22 탐험 프로토타입 업데이트
- 바텀웨이마을에서 바텀웨이 숲으로 이동하는 탐험 버튼을 추가했습니다.
- 종족·직업 선택, 주사위 기반 캐릭터 생성, 종족 보정, 시작 골드 200G를 연결했습니다.
- 바텀웨이마을의 기존 NPC 8명의 테스트용 능력치 표시를 추가했습니다.
- 숲의 임시 테스트 마물 3종과 능력치 확인 화면을 추가했습니다.
- NPC 능력치만 임시 표시용으로 생성합니다. 마물 데이터는 등록하지 않았습니다.
- 기존 코드에 있던 JavaScript 줄바꿈 이스케이프 오류를 정리했습니다.

## 숲·마물·도서관 의뢰·인벤토리 (2026-11-22)
- 약골 고블린, 약골 거미, 고블린, 약골 미믹의 사용자가 정한 기본 능력치를 등록했습니다.
- 약골 미믹의 두 외형은 숲의 '보물 속 미믹'과 도서관의 '책의 미믹'이며, 동일한 기본 능력치를 공유합니다. 미기재된 미믹 방어력은 숫자로 채우지 않습니다.
- 숲과 도서관은 각각 50발자국마다 1d100을 굴리고 40 이하이면 조우합니다(조우 40%, 비조우 60%).
- 고블린 계열 출현 가중치는 다른 마물보다 낮은 0.5로 임시 설정되어 있으며, 사용자가 비중을 정하면 조정할 수 있습니다.
- 숲의 큰사과는 1~200발자국 사이의 무작위 위치에 생성되며, 획득하면 다음 출현 지점을 다시 무작위로 정합니다.
- 도서관 의뢰는 책의 미믹 3마리 처치, 보상은 20G와 스킬북 1개입니다.
- 마물 처치 시 마물 유해 1개를 확정 드롭합니다. 길드 매입 기능은 연결했고 매입가는 사용자 미정이므로 판매는 비활성 상태입니다.
- 인벤토리는 아이템 30칸이며, 각 아이템을 별도 슬롯으로 보관합니다.
- 현재 전투 엔진이 연결되기 전이므로, 조우 화면의 '테스트용 처치 결과 등록'은 드롭과 의뢰 진행을 시험하기 위한 임시 기능입니다.

- 전체 스킬 습득 서적, 장착·각성, 아이템 구매·사용
- AI GM 서버 연동 및 계정·클라우드 세이브

## 바텀웨이마을 시설 데이터 (기초 골격)
- `src/data.js`에 상점·도서관·성소·훈련장·길드의 사용자 확정 설정을 구조화했습니다.
- 시설 메뉴에서 각 시설의 NPC, 상품, 가격, 입장료, 이용 규칙, 의뢰 게시판 정보를 확인할 수 있습니다.
- `assets/facilities.svg`는 시설 화면에서 사용하는 자체 제작 SVG 아이콘입니다.
- 아직 정하지 않은 무기 수리비, 매입가, NPC 전용 능력치 생성 규칙, 전투 스킬 피해 공식 및 실제 퀘스트 보상 공식은 구현하지 않았습니다.
- 이 단계의 시설 화면은 정보 열람용 골격입니다. 실제 구매·부활·훈련·전투는 해당 경제·전투 규칙이 확정된 뒤 연결합니다.


## 2026-11-22 탐험 조작 수정
- 캐릭터 생성 전에도 숲 진입과 이동을 허용해 탐험 화면을 확인할 수 있습니다. 전투 등 캐릭터 능력치가 필요한 기능은 별도 연결이 필요합니다.
- 방향키/WASD와 화면 방향 패드를 누르고 있는 동안 연속 이동합니다.
- 장면 배경을 클릭하면 해당 방향으로 이동합니다.
- 큰사과의 다음 출현 지점을 1~200발자국 사이에서 정하도록 변경해 기존보다 빈도를 낮췄습니다.
- 마물 조우 판정은 50발자국마다 1d100, 40 이하 출현으로 유지합니다.
