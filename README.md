# AI-TRPG

새로 개발하는 판타지 TRPG 프로젝트입니다. 기존 `dice-rpg` 저장소 및 DICE RPG Ver 1.4 파일은 별도로 보존하며 이 저장소에서 수정하지 않습니다.

## 현재 프로토타입
- 풀스크린 중심의 반응형 게임 화면
- 바텀웨이마을 초기 장면과 모험가 캐릭터 콘셉트
- CSS 기반 대기, 이동, 대화, 검 휘두르기 애니메이션
- 이동·대화·장소 조사·훈련 로그
- 브라우저 로컬 저장을 이용한 초기 활동 기록
- PC 및 모바일 레이아웃 대응

## 실행
정적 웹 프로젝트입니다. `index.html`을 정적 서버로 열거나 Vercel에 배포할 수 있습니다.

## 구현 경계
이 버전은 시각·조작 프로토타입입니다. 실제 계정 인증, 클라우드 저장, 멀티플레이, AI Game Master API, 주사위 기반 명중/방어 판정, 완성된 캐릭터 생성/성장, 확정된 전체 지도와 세계 데이터는 아직 연결되지 않았습니다. 임시 UI 값은 실제 게임 규칙으로 간주하지 않습니다.

공격 연습 버튼은 시각 효과만 재생하며 피해나 명중 판정을 실행하지 않습니다. 실제 전투 구현에서는 기존 DICE RPG의 명중률·명중·방어 규칙을 원본 기준으로 이식하되, 두 프로젝트의 코드는 독립적으로 유지합니다.

## 2026-11-22 탐험 프로토타입 업데이트
- 바텀웨이마을에서 바텀웨이 숲으로 이동하는 탐험 버튼을 추가했습니다.
- 종족·직업 선택, 주사위 기반 캐릭터 생성, 종족 보정, 시작 골드 200G를 연결했습니다.
- 바텀웨이마을의 기존 NPC 8명의 테스트용 능력치 표시를 추가했습니다.
- 숲의 임시 테스트 마물 3종과 능력치 확인 화면을 추가했습니다.
- NPC·마물 능력치는 캐릭터 공통 주사위 범위를 임시 적용한 초안이며, 별도 생성 규칙이나 밸런스로 확정된 것이 아닙니다.
- 기존 코드에 있던 JavaScript 줄바꿈 이스케이프 오류를 정리했습니다.

## 아직 연결되지 않은 기능
- 실제 전투 피해 계산 및 스킬별 SP 사용
- NPC·마물 전용 스탯 생성 규칙과 밸런스
- 전체 스킬 습득 서적, 장착·각성, 아이템 구매·사용
- AI GM 서버 연동 및 계정·클라우드 세이브

## 바텀웨이마을 시설 데이터 (기초 골격)
- `src/data.js`에 상점·도서관·성소·훈련장·길드의 사용자 확정 설정을 구조화했습니다.
- 시설 메뉴에서 각 시설의 NPC, 상품, 가격, 입장료, 이용 규칙, 의뢰 게시판 정보를 확인할 수 있습니다.
- `assets/facilities.svg`는 시설 화면에서 사용하는 자체 제작 SVG 아이콘입니다.
- 아직 정하지 않은 무기 수리비, 매입가, NPC·마물 전용 능력치 생성 규칙, 전투 스킬 피해 공식 및 실제 퀘스트 보상 공식은 구현하지 않았습니다.
- 이 단계의 시설 화면은 정보 열람용 골격입니다. 실제 구매·부활·훈련·전투는 해당 경제·전투 규칙이 확정된 뒤 연결합니다.
